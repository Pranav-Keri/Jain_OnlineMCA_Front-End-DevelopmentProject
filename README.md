# This is my First Front End Development Project on Jain Online MCA Program!

# VideshiYatra 🌍

VideshiYatra is a responsive travel website created using HTML, CSS, Bootstrap and JavaScript.

The website allows users to explore travel packages, view services, browse travel galleries, register/login and book trips online.

---

# Features

## Checkpoint 1
- Responsive Navigation Bar
- Dropdown Menu for Packages
- Hero Section with Background Image
- Dynamic Country Name Animation
- Book Now Button

### Problem Statement

#### Checkpoint 1
A. Create Welcome page, `index.html`

B. Create a Navigation menu at the top in which following content should appear:
- Brand Name or Brand Logo or Both Brand Name & Logo (Left aligned)
- Add 6 Navigation menu to the right of brand name:
  - Home
  - Book
  - Packages
  - Services
  - Gallery
  - About

Packages menu contains dropdown options:
- United States
- India
- France
- Germany

Add Login & Register buttons to the right side.

C. Add one background image below the navigation bar:
- Width: 100%
- Height: 90vh

D. Add centered text on background image:
- Welcome to BrandName
- Visit Placename
- Dynamic country names changing automatically
- Book Now button

## Checkpoint 2
- Booking Form
- Form Validation using JavaScript
- Popular Packages Section
- Bootstrap Cards
- Star Ratings using Bootstrap Icons
- Services Section

### Problem Statement

#### Checkpoint 2

A. Create 2 sections with 50% width each:
- Left side contains image
- Right side contains booking form

Booking form includes:
- Destination dropdown
- Number of persons
- Start Date
- End Date
- Description textarea
- Book Now button

Validation Requirements:
- Start date should be future date
- End date should be greater than start date
- Description minimum 50 characters and maximum 500 characters
- Successful booking alert message

B. Create Package Gallery:
- 3 packages per row
- Total 9 packages
- Each package shown in card format

Each card contains:
- Image
- Place Name
- Description
- Price in USD
- Rating
- Book Now button

C. Add Services Section:
- Minimum 6 services
- Includes custom services
- Designed using Bootstrap cards
